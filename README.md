# ΒΑΣΗ Dashboard

Offline/online εργαλείο για τον Κώδικα Χωροταξίας-Πολεοδομίας (Ν.5306/2026, ΦΕΚ Α΄ 88/8.6.2026):
αναζήτηση στα άρθρα, προβολή άρθρου με παραπομπές, αντιστοίχιση παλιού↔νέου δικαίου,
πλοήγηση ανά Μέρος/Τμήμα, και εβδομαδιαίες ενημερώσεις ΦΕΚ/εγκυκλίων, τροποποιήσεις του Κώδικα με χρωματική σήμανση, ιστορικό ΝΟΚ.

Τα δεδομένα (`vasi_data.js`, `settlements.js`, `domiki_updates.js`) παράγονται αυτόματα από το
ΒΑΣΗ Engine (`build_index.py`, `watch_domiki.py`). Μην τα επεξεργάζεσαι χειροκίνητα.

Πηγή: Εθνικό Τυπογραφείο (ΦΕΚ). Το εργαλείο δεν υποκαθιστά το ΦΕΚ.
